# VALENTINA — Luxury Jewelry E-Commerce

A responsive luxury jewelry e-commerce website designed and developed as a portfolio project.

## ✨ Features

- Luxury jewelry product catalog
- Product search
- Product filtering and sorting
- Product detail views
- Product image gallery
- Wishlist functionality
- Shopping cart
- Customer reviews
- Dark and light theme
- Responsive design for different screen sizes
- Persistent cart, wishlist, and theme preferences

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Google Fonts
- LocalStorage

## 🌐 Live Demo

[View VALENTINA Live Website](https://rajput20200.github.io/valentina-jewelry-store/)

## 📌 Project

**VALENTINA** is a luxury jewelry storefront created to demonstrate modern e-commerce UI/UX, responsive web design, interactive product browsing, and client-side functionality.
